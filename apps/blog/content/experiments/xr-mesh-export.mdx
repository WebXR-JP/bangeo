Meta Quest 3 / 3S / Pro の room mesh（Quest の scene capture で取得できる部屋形状メッシュ）を WebXR から扱うデモです。passthrough 越しにメッシュがワイヤーフレームで可視化され、semantic label（床・壁・天井・家具）ごとに色分け表示されます。

`EXPORT GLB` ボタンを押すと、その瞬間のメッシュと平面を `.glb` ファイルとして Quest のダウンロードフォルダに保存します。保存された GLB は Blender や Three.js ビューワで開けるため、個人の部屋スキャン用途にも使えます。

使用する WebXR 機能: `mesh-detection`（Quest 独自拡張）、`plane-detection`、`anchors`、`dom-overlay`。Android Chrome や iOS Safari は Mesh Detection 未対応のため非対応です。

## 用語メモ

| 用語 | このページでの意味 |
| --- | --- |
| scene capture | Quest の部屋形状取得機能。room mesh と semantic label をまとめて取得する |
| room mesh | scene capture で取得できる、現実空間の形状メッシュ |
| XRMeshDetection | WebXR 仕様で mesh を検出・更新する機能。Quest では scene capture 経由で提供される |
| semantic label | room mesh の各部分に付与されるラベル（床・壁・天井・家具など）。Quest Scene Model による分類 |
