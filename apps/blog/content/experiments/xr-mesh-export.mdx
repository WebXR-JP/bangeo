Meta Quest 3 / 3S / Pro のシーンメッシュ機能を WebXR から扱うデモです。パススルー越しに部屋のメッシュがワイヤーフレームで可視化され、セマンティックラベル（床・壁・天井・家具）ごとに色分け表示されます。

`EXPORT GLB` ボタンを押すと、その瞬間のメッシュと平面を `.glb` ファイルとして Quest のダウンロードフォルダに保存します。保存された GLB は Blender や Three.js ビューワで開けるため、個人の部屋スキャン用途にも使えます。

使用する WebXR 機能: `mesh-detection`（Quest 独自拡張）、`plane-detection`、`anchors`、`dom-overlay`。Android Chrome や iOS Safari は Mesh Detection 未対応のため非対応です。
