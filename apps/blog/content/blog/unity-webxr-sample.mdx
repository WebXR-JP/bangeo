## はじめに

UnityでWebXRコンテンツを作成し、ブラウザから直接VR/AR体験を提供する方法を解説します。

デモURL：[https://yushimatenjin.github.io/unity-webxr-sample/](https://yushimatenjin.github.io/unity-webxr-sample/)

![Unity WebXR Sampleのデモ画面 - VR/ARモードで動作するWebXRコンテンツ](/images/tech-articles/unity-webxr/unity-webxr-sample-demo.png)

### 作成環境

| 項目 | バージョン |
| --- | --- |
| Unity | 6000.3.4f1 |
| レンダリング | Universal Render Pipeline（URP） |
| プラットフォーム | WebGL Build Support |

## セットアップ手順

### Step 1：プロジェクト作成

Unity Hubを起動し、新規プロジェクトを作成します。テンプレートは**3D (URP)**を選択してください。

### Step 2：WebXR Exportパッケージの導入

WebXR Exportパッケージのインストールには2つの方法があります。

#### 方法A：OpenUPM経由（推奨）

1. **Edit > Project Settings > Package Manager**を開きます。
2. **Scoped Registries**に以下を追加します。
   - Name：`OpenUPM`
   - URL：`https://package.openupm.com`
   - Scope：`com.de-panther`
3. **Window > Package Manager**を開きます。
4. **My Registries**から「WebXR Export」と「WebXR Interactions」をインストールします。

![Unity Project Settings - Package Managerの設定画面でOpenUPMのスコープを追加](/images/tech-articles/unity-webxr/project-settings-package-manager.png)

![Unity Package Manager - OpenUPMからWebXR ExportとWebXR Interactionsをインストール](/images/tech-articles/unity-webxr/package-manager-openupm.png)

#### 方法B：Git URL経由

**Window > Package Manager > Add package from git URL**で以下を順番にインストールします。

```
https://github.com/nicovr/unity-webxr-export.git?path=/Packages/webxr
https://github.com/nicovr/unity-webxr-export.git?path=/Packages/webxr-interactions
```

### Step 3：WebGLテンプレートのコピー

1. **Window > WebXR > Copy WebGLTemplates**を実行します。
2. Unityを再起動します。

![Unity Windowメニュー - WebXR > Copy WebGLTemplatesを実行](/images/tech-articles/unity-webxr/window-webxr-copy-webgl-templates.png)

> WebGLテンプレートのコピーを忘れると、ビルド時にWebXR用のHTMLテンプレートが見つからずエラーになります。

### Step 4：XR Plug-in Managementの設定

1. **Edit > Project Settings > XR Plug-in Management**を開きます。
2. **WebGL**タブを選択します。
3. **WebXR Export**にチェックを入れます。

### Step 5：シーンの設定

1. デフォルトの**Main Camera**を削除（または無効化）します。
2. **Packages/WebXR Interactions**から`WebXRCameraSet.prefab`をシーンにドラッグします。
3. 必要なオブジェクト（Plane、Cubeなど）を追加します。

![Unity Hierarchy - WebXRCameraSetプレハブとCubeを配置したシーン構成](/images/tech-articles/unity-webxr/hierarchy-webxr-cameraset-cube.png)

### Step 6：ビルドと実行

1. **File > Build Settings**を開きます。
2. **WebGL**プラットフォームを選択し、**Switch Platform**をクリックします。
3. **Player Settings > Resolution and Presentation**でWebGL Templateを**WebXR2020**に設定します。
4. **Build And Run**を実行します。

## テスト方法

### PCでのテスト

1. ChromeまたはEdgeをインストールします。
2. [WebXR API Emulator](https://chrome.google.com/webstore/detail/webxr-api-emulator/)拡張機能をインストールします。
3. ビルドしたHTMLをローカルサーバーで開きます。
4. F12でDevToolsを開き、WebXR Emulatorタブで仮想デバイスを操作します。

### スマートフォンARでのテスト

1. Android端末でChromeを開きます。
2. HTTPS経由でビルドURLにアクセスします。
3. 「START AR」ボタンをタップします。

> iOSのSafariはWebXRに未対応です。iOSで試すには、EyeJackのようなApp Clip対応ビューアーが必要です。

### VRヘッドセットでのテスト

1. Quest Browserを開きます。
2. ビルドURLにアクセスします。
3. 「ENTER VR」ボタンをタップします。

## トラブルシューティング

| 問題 | 原因 | 対処法 |
| --- | --- | --- |
| VR/ARボタンが非活性 | WebXR Exportが有効になっていない | XR Plug-in Managementの設定を確認 |
| テンプレートが見つからない | WebGLテンプレートがコピーされていない | Copy WebGLTemplatesを実行し、Unityを再起動 |
| ビルドエラーが発生 | WebGLモジュールが未インストール | Unity HubからWebGL Build Supportをインストール |
| ビルドが表示されない | HTTPS非対応 | ローカルサーバーにHTTPSを設定、またはGitHub Pages等にデプロイ |
