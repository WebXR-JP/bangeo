WebXRやWebARの更新は、仕様書やGitHubだけでなく、開発者イベントやブラウザベンダーの発表にもよく現れます。

BANGEOでは、WebXRを学ぶ開発者向けに、WebXR / WebAR / Spatial Web / Quest Browser / Safari visionOS / Chrome / W3C標準化に加えて、日本国内のXRイベントやデバイスメーカー発表に関係しそうなイベントを追跡する「WebXRイベントウォッチ」を始めます。

イベントそのものを追うのではなく、**「このイベントの後に、どのAPI、ブラウザ、フレームワーク、学習ページを確認すべきか」** を整理するのが目的です。

## なぜイベントを見るのか

WebXR開発者にとって重要な更新は、必ずしも仕様リポジトリだけに現れるわけではありません。たとえば、ブラウザベンダーの基調講演、開発者向けセッション、公式ブログ、リリースノート、動画、GitHub差分が組み合わさって、後から「WebXRの実装状況が変わっていた」と分かることがあります。

BANGEOでは、イベントを「ニュースの山」としてではなく、**WebXR開発者が後で確認すべき一次情報が増えるタイミング**として扱います。

たとえばMeta ConnectならQuest BrowserやHorizon OS、Google I/OならChrome / Android XR / Web Platform、WWDCならSafari / WebKit / visionOS、TPACならWebXR仕様やImmersive Web Working Groupの議論を追います。国内ではXR Kaigi、CEATEC、Tokyo Game Show、XR & Metaverse Fair、IVSなどを見て、デバイスメーカーや国内XR企業の発表もWebXR開発者目線で拾います。

## Meta Connect 2026を重点確認する理由

Meta Connect 2026は、2026年9月23〜24日に開催予定です。Meta公式のConnectページでは、今年のプログラム発表、登壇者、注目技術の更新を受け取るためのライブ配信登録が案内されています。

BANGEO的には、ここから次のような更新を重点確認します。

- Quest Browserのリリースノート
- WebXR対応状況
- WebXR Depth / depth projectionまわりの変化
- Experimental WebGPU
- Horizon OSのブラウザ体験
- AIグラスとWeb体験の接点
- 空間ブラウザUI

Meta Connectの発表は、WebXRそのもののAPI更新だけでなく、Quest Browserで「何が現実的に使えるようになったか」を見直すきっかけになります。

## どう確認するか

BANGEOではイベントを毎日すべて深掘りするのではなく、開催時期に応じて確認頻度を変えます。

- 90日以上前: 月1チェック
- 30〜90日前: 週1チェック
- 30日前〜開催前: 毎日軽く確認
- 開催中: 毎日確認
- 開催後7日: 公式ブログ、動画、リリースノート、GitHub差分を回収
- 反映後: archived

状態は `announced`、`upcoming`、`schedule-live`、`live`、`recap-needed`、`archived` の6段階で管理します。

## BANGEOでの反映先

イベント由来の更新は、単発ニュースで終わらせず、次の導線にします。

**イベント → 一次情報確認 → /webxr-status更新 → 実験ページ追加 → 解説記事化**

たとえば、Meta Connect 2026でQuest BrowserやHorizon OSのWebXR関連発表があれば、まず一次情報を確認し、必要に応じて[/webxr-status](/webxr-status)やQuest Browserメモ、WebGPU検出デモ、Depth Projection関連実験に反映します。

Google I/OやWWDCの発表も同様に、Chrome / Web Platform / Safari / WebKit / visionOSの観点で整理し、WebXR開発者に関係する部分だけを抽出します。国内イベントでは、XR専業カンファレンスだけでなく、ゲーム、家電、スマートグラス、産業向けXR、スタートアップ展示の中から、Webで実装できる体験やBANGEOのデバイス一覧・活用事例に反映できる情報を拾います。ニュース記事、X、個人ブログ、イベントまとめ記事は発見用として扱い、公開本文の根拠には公式ページ・メーカー公式ニュース・主催者発表を優先します。
