WebXRの更新は、仕様書やGitHubだけでなく、開発者イベントやブラウザベンダーの発表にも現れます。

BANGEOでは、WebXR / WebAR / Spatial Web 開発者向けに、標準化、ブラウザ、国内XRイベント、デバイス展示を追跡します。

イベントそのものを追うのではなく、**WebXR開発者が後で確認すべき一次情報が増えるタイミング**として扱い、必要な更新をイベントページに集約します。

## 何を見るのか

- Meta Connect: Quest Browser / Horizon OS / MR
- Google I/O: Chrome / Web Platform / Android XR
- WWDC: Safari / WebKit / visionOS
- TPAC: WebXR仕様 / Immersive Web
- 国内イベント: XR Kaigi、CEATEC、XR・メタバース総合展、TGS など

Meta Connect、Google I/O、WWDC、TPAC、XR Kaigi、XR・メタバース総合展などを代表例として追跡します。イベント別の状態、見るポイント、一次情報リンクは一覧ページ側で更新します。
