## WebXRでのWebGPU対応の流れ

Quest Browserでは、WebXRでのWebGPU対応に続いて関連機能が追加されています。

| Browser | 公式リリースノートにあるWebXR / WebGPU関連の更新 |
| --- | --- |
| [146.0](https://developers.meta.com/horizon/downloads/package/browser/146.0/)（2026年4月21日） | WebXRでの実験的なWebGPU対応 |
| [149.1](https://developers.meta.com/horizon/downloads/package/browser/149.1/)（2026年7月27日） | WebGPU用Space Warp Layer対応 |
| [150.1](https://developers.meta.com/horizon/downloads/package/browser/150.1/)（2026年8月28日） | WebXRのWebGPU描画でfoveationを実験的にサポート |

WebGPUでの描画が可能になり、Space Warp Layerに続いて描画負荷を調整する機能が加わりました。

## foveationで何が変わるか

今回の対応は**fixed foveation**です。視線を追跡する方式ではなく、画面の中心と周辺で描画密度を変えます。[Metaの解説](https://developers.meta.com/horizon/documentation/web/webxr-ffr/)によると、GPUのピクセル処理が負荷の原因となっている場面で効果が期待できます。一方、文字や輪郭のはっきりした画像は周辺部の変化が目立つことがあります。

WebXRでは[`XRProjectionLayer.fixedFoveation`](https://www.w3.org/TR/webxrlayers-1/#dom-xrprojectionlayer-fixedfoveation)で設定します。この値はVRの実行中にも変更できます。具体的な描画方法はブラウザに委ねられているため、画質とGPU負荷は対象の端末で確かめる必要があります。

Quest Browser 150.1でのサポートは実験的です。Metaのリリースノートには、機種ごとの効果や性能向上率は示されていません。
