## はじめに

Meta Questのブラウザ（Quest Browser）で特定のURLを開きたいとき、ヘッドセットを被ってバーチャルキーボードで長いURLを入力するのは手間がかかります。

Metaの「**Web Launch**」を使えば、PCやスマートフォンのブラウザからワンクリックでQuestへURLを送れます。USB接続も開発者モードも不要で、同じMetaアカウントでログインしていれば誰でも利用できます。

## Web Launchの概要

Web LaunchはMeta公式のURL送信機能です。次のURLへアクセスするだけで、Quest Browserで開きたいWebページをQuestへ送れます。

```
https://www.oculus.com/open_url/?url=<送りたいURL>
```

| 項目 | 内容 |
| --- | --- |
| USB接続 | 不要 |
| 開発者モード | 不要 |
| 必要なもの | 同じMetaアカウントでログイン済みのPC・スマートフォンとQuest |
| 対応URL | HTTPSのみ |

## 使い方

### Step 1：Metaアカウントへのログイン

PCやスマートフォンのブラウザで[meta.com](https://www.meta.com/quest/)へアクセスし、Questと同じMetaアカウントでログインしておきます。

### Step 2：Web LaunchのURLへアクセス

ブラウザのアドレスバーに次のURLを入力します。`bangeo.net`の部分を送りたいURLに置き換えてください。

```
https://www.oculus.com/open_url/?url=https%3A%2F%2Fwww.bangeo.net
```

### Step 3：「SAVE TO MR」のクリック

アクセスすると次の画面が表示されます。送りたいURLが表示されていることを確認し、「**SAVE TO MR**」ボタンをクリックします。

![Web Launchの「Visit an experience in MR」画面 - SAVE TO MRボタンでQuestにURLを送信できる](/images/tech-articles/meta-quest-url-launch/web-launch-save-to-mr.png)

### Step 4：保存完了とQuest側での起動

「**Saved**」ダイアログが表示されれば送信完了です。OKを押して閉じます。

![Web Launchの保存完了ダイアログ - Questから後でアクセスできる](/images/tech-articles/meta-quest-url-launch/web-launch-saved.png)

保存されたリンクはQuestのヘッドセットやMeta Horizonモバイルアプリの保存済みアイテムに表示されます。Questを被って一覧から選択するだけで開けます。

## Webサイトへの「Questで開く」ボタン設置

Web Launchは自分で使うだけでなく、Webサイトにリンクとして埋め込めます。PCやスマートフォンでWebXRコンテンツを見つけたユーザーを、スムーズにQuestへ誘導したい場面で便利です。

```html
<a href="https://www.oculus.com/open_url/?url=https%3A%2F%2Fwww.bangeo.net">
  Meta Questで開く
</a>
```

> Metaの公式ガイドラインでは、ボタンやリンクにMeta Questのブランディングを使用することが推奨されています。

## 注意点

### HTTPSの必須条件

Web Launchで送れるURLは**HTTPSのみ**です。`http://`で始まるURLやローカルネットワークのURL（`192.168.x.x`など）は送れません。

> ローカル開発サーバーのURLを送りたい場合は、[ngrok](https://ngrok.com/)などのトンネリングツールでHTTPSの公開URLを作成する方法があります。

### 同一Metaアカウントでのログイン

PC・スマートフォンのブラウザとQuest側で**同じMetaアカウント**にログインしている必要があります。

### URLエンコードの必要性

送信先URLに`:`、`/`、`?`、`=`、`&`などの特殊文字が含まれる場合は、URLエンコードが必要です。

| 元のURL | エンコード後 |
| --- | --- |
| `https://www.bangeo.net` | `https%3A%2F%2Fwww.bangeo.net` |
| `https://www.bangeo.net/path?q=test` | `https%3A%2F%2Fwww.bangeo.net%2Fpath%3Fq%3Dtest` |

## まとめ

Meta Questの「**Web Launch**」は、`oculus.com/open_url/`へアクセスするだけでQuestにURLを送れるシンプルな仕組みです。

- USB接続や開発者モードが不要で誰でも使える
- Webサイトに組み込んでユーザーをQuestへ誘導できる
- WebXRコンテンツの共有・配布に活用しやすい
