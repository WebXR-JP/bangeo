8th Wall エンジンを読み込めませんでした

8thwall/8thwall からソースをビルドするか、 8thwall/engine から xr-standalone.zip をダウンロードしてください。

Image Targets を使うには、ターゲット画像を事前に生成する必要があります：

cd apps/image-target-cli npm install node ./src/index.js

生成された JSON を XR8.XrController.configure() で読み込みます。
