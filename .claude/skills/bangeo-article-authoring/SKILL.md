# BANGEO記事制作

`apps/blog/content/blog/` に、読者が変更点や技術を理解し、必要なら再現できる日本語記事を書く。文体・分類は近い既存記事、frontmatterは現行スキーマを確認する。

- 最新情報・バージョン・対応状況は一次情報で確認する。発表、利用可能、実機検証済みを区別する。
- 公的な技術名称を保ち、初出で自然な日本語の説明を添える。絵文字や運用・編集メモを本文に入れない。
- NEWSは何がいつ変わり誰に影響するか、TECH/GUIDEは対象環境と再現方法を中心にする。要件に必要なサンプルを省略しない。
- 公開リポジトリに非公開情報を置かない。

## 作業に応じた参照

[reference.md](reference.md) の該当節だけ読む。

| 作業 | 節 |
| --- | --- |
| 新規記事・メタデータ変更 | MDX frontmatter |
| 画像追加・変更 | サムネイル（スタイル・配置・台帳） |
| 調査メモから記事化 | 公開本文の読者向けチェック |
| 技術解説・実装例 | WebXR / WebGPU記事、PlayCanvas / WebXRデモの確認項目 |
| 用語・タイトル調整 | 用語とSEO |

## 完了

出典、対象のMDX構文・frontmatter、変更したリンクと画像を確認し、内容や表示に応じた検証まで進める。誤字だけの修正で画像を作り直したり、記事全体を再構成したりしない。ビルドは `pnpm -C apps/blog build`。画像最適化の副作用を含め差分を確認し、対象外の変更を混ぜない。確認できなかった出典や実行環境は明示する。
